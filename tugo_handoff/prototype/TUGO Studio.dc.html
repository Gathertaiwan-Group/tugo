為什麼創作，值得走進日常？

很多好作品，被按了讚，然後就被滑走了。我們覺得可惜。

ABOUT — 關於我們

好作品，
不只值得被看見。

工作室／打樣過程照（待提供）

「圖個有意思」是一個替新銳藝術家，把作品變成日常用品的品牌。

名字取自台語與華語裡都常聽到的一句話——做這件事，不為別的，就圖個有意思。但「有意思」不等於隨便：我們認真挑選作品、反覆打樣，並把每一位創作者的名字放在商品最前面。

我們相信，作品被穿上、被使用、被送給喜歡的人，就是它最好的展覽。

01

創作者優先

清楚署名、透明的授權範圍與分潤方式，所有條件依合作合約約定，不模糊帶過。

02

把作品做成好東西

材質、印刷與工法依作品特性挑選；藝術家參與校色與打樣確認。

03

有趣，是認真的

我們喜歡讓人會心一笑的作品，也用同樣的心情對待每一次出貨與客服。

我們能一起做的事

VALUE 01

作品保有你的名字

每件商品清楚署名，並附作品故事與藝術家介紹頁。

VALUE 02

透明的授權條款

授權範圍、期間、分潤方式皆以書面合約明訂，簽約前可充分討論。

VALUE 03

從打樣到出貨

選材、打樣、生產、倉儲與客服由團隊負責，你參與校色與確認。

VALUE 04

策展式的露出

透過聯名企劃、電子報與社群介紹作品；實際曝光方式依企劃內容而定。

三種合作方案

PLAN A ・ EMERGING

新銳共創

適合剛開始經營作品、尚無商品化經驗的創作者。由團隊協助挑選適合的作品與品項，小量試製、線上首發。

  • 1–3 款入門品項（貼紙、明信片、托特包等）
  • 商品化與定價建議
  • 藝術家個人頁面
分潤比例、授權期間、是否獨家：依合作合約約定
最常見PLAN B ・ SIGNATURE

藝術家聯名

適合已有穩定風格與受眾的創作者。共同開發一個完整系列，從服飾到生活小物，並有專屬的系列頁面。

  • 4–8 款系列商品共同開發
  • 藝術家參與打樣與校色
  • 系列故事頁與首頁專題
分潤比例、授權期間、是否獨家：依合作合約約定
PLAN C ・ LIMITED

限定企劃

以主題或展覽為核心的限量計畫，例如簽名編號版畫、展覽周邊、快閃活動商品。

  • 限量版畫／簽名編號品
  • 展覽或活動周邊
  • 期間限定販售
分潤比例、授權期間、是否獨家：依合作合約約定

合作流程

  1. 1提交申請填寫下方表單並附作品集連結。
  2. 2作品初審團隊評估作品與商品化方向（審核時程將另行通知）。
  3. 3線上會談討論合作方案、品項與時程。
  4. 4簽訂合約明訂授權範圍、期間與分潤方式。
  5. 5打樣與上架確認樣品後生產、拍攝並上架。

常見問題

需要已經有商品經驗嗎？不需要。「新銳共創」方案就是為第一次商品化的創作者設計。
作品著作權歸誰？著作權仍屬於創作者；我們依合約取得特定商品、期間與通路的使用授權。
分潤怎麼計算？保證收入嗎？分潤比例與結算方式依合作合約約定。我們不承諾固定收入或保證銷量、曝光。
一定要獨家嗎？不一定，是否獨家依方案與合約內容而定，簽約前會清楚說明。
